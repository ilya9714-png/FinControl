# FinControl — сборка APK без компьютера

## Самый простой способ с телефона

1. Создай бесплатный аккаунт на GitHub и создай новый репозиторий, например `FinControl`.
2. Распакуй этот ZIP на телефоне (если файловый менеджер не умеет распаковывать — можно загрузить ZIP в GitHub как архив только после распаковки; GitHub не распаковывает ZIP при обычной загрузке).
3. В GitHub открой репозиторий → **Add file → Upload files** и загрузи содержимое папки `FinControl`, включая папку `.github`.
4. Перейди **Actions → Build FinControl APK → Run workflow**.
5. После окончания сборки открой завершённый workflow и скачай artifact `FinControl-debug-apk`.
6. Внутри будет `app-debug.apk`. Открой его на Android и установи.

Workflow уже настроен: Android SDK 35, Java 17 и Gradle 8.9 устанавливаются автоматически.
